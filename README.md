## Быстрый старт

```bash
# 1. Создать БД
createdb shoe_store_2

# 2. Установить зависимости
pip install -e .

# 3. Применить миграции (включая data migration для 3НФ)
python manage.py migrate

# 4. Загрузить тестовые данные из Приложения 2
python manage.py import_data

# 5. Запустить сервер
python manage.py runserver
```

Приложение будет доступно по адресу `http://127.0.0.1:8000/`.

## Структура БД (3НФ)

```
Role ─────────────────── User
                           │
Supplier ──┐               │
Category ──┼── Product ────┤
Manufact.──┘       │       │
                   │       │
              OrderItem    │
                   │     Order ── PickupPoint
                   └───────┘
```

**Таблицы-справочники:** `Role`, `Supplier`, `Category`, `Manufacturer`, `PickupPoint`  
**Основные таблицы:** `User`, `Product`, `Order`, `OrderItem`

Все связи реализованы через внешние ключи. Каскадное удаление используется только там, где оно логически оправдано (удаление заказа удаляет его позиции). Для всех остальных FK используется `PROTECT` — попытка удалить справочник, на который есть ссылки, вернёт ошибку.

## Функционал

### Товары
- Карточки с фото, ценой, скидкой, количеством, категорией, производителем
- Заглушка `picture.png` при отсутствии фото
- Выделение зелёным: скидка > 15%
- Выделение голубым: остаток = 0
- Поиск в реальном времени по всем текстовым полям (500 мс debounce)
- Фильтр по поставщику; сортировка по количеству (↑ ↓)
- Клик по карточке (роль admin) → форма редактирования
- Загрузка фото с автоматическим масштабированием до 300×200 пикс.
- Замена фото → старый файл удаляется автоматически
- Форма добавления показывает предварительный ID (MAX + 1)
- Удаление блокируется, если товар используется в заказах (`PROTECT`)

### Заказы
- Таблица: №, клиент, статус, дата, пункт выдачи, код, количество позиций
- Клик по строке (роль admin) → форма редактирования
- Форма содержит inline-формсет позиций (товар + количество) с добавлением и удалением строк
- Статус задаётся через выпадающий список: Новый / В сборке / Готов к выдаче / Завершён / Отменён

---

## Формы добавления / редактирования

- Поле **ID**: при добавлении — отключённое поле с предварительным значением `MAX(id)+1`; при редактировании — только для чтения
- Поставщик, категория, производитель — **выпадающие списки** из справочных таблиц
- Валидация: цена ≥ 0 (дробная), количество ≥ 0 (целое), код получения ≥ 0
